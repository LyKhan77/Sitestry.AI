# Issue Tracker & Task Management

This repository tracks active tasks and engineering phases locally via:

1. **Phase Task Checklist**: [`todo.md`](../../todo.md) at the repository root (overwritten at the start of each new phase once all tasks from the previous phase are verified complete).
2. **Release & State History**: [`CHANGELOG.md`](../../CHANGELOG.md) at the repository root.
3. **Superpowers Plans & Specs (Local Uncommitted Record)**:
   - Plans: `docs/superpowers/plans/`
   - Specifications: `docs/superpowers/specs/`
   - *Note*: Per `AGENTS.md` rules, files inside `docs/superpowers/plans/` and `docs/superpowers/specs/` are excluded via `.gitignore` and must **never** be committed to Git.
